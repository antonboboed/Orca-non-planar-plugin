# Проверка G-code для неплоской печати (черновик)

Независимая проверка готового G-code. Не меняет файл. Нужна только стандартная библиотека Python 3.

```bash
python3 gcode_check.py path/to/file.gcode            # лимит уклона 12°
python3 gcode_check.py file.gcode --max-angle 10     # строже
python3 -m unittest -v test_gcode_check.py           # тесты
```

Код возврата: `0` без ошибок, `1` если найдены ошибки.

## Что проверяется

| Код | Уровень | Смысл |
|---|---|---|
| `SLOPE` | ошибка | уклон движения (abs(dz) / dxy) больше лимита; учитываются движения с dxy ≥ 0.5 мм |
| `COLLISION` | ошибка | сопло проходит ближе, чем допускает модель кончика и конуса, к уже напечатанному материалу, который выше его на допуск |
| `Z_NEGATIVE` | ошибка | Z < 0 |
| `UNITS` | ошибка | G20 (дюймы) |
| `UNCHECKED_HIGH` | предупреждение | рядом с соплом есть материал выше 2.5 мм. Блок хотэнда здесь не моделируется, проверьте вручную |
| `ARC` | предупреждение | дуга G2/G3 не анализируется |
| `HOME` | предупреждение | G28: Z неизвестен до следующего абсолютного Z |

Информация (не ошибка): число экструзионных движений при изменении Z (`nonplanar_extrusion_moves`),
максимальный уклон, диапазон Z.

## Модель хотэнда

Значения взяты из `NonplanarClearanceModel` в патче
[fich-l/orcaslicer-nonplanar](https://github.com/fich-l/orcaslicer-nonplanar) (orca-nonplanar.patch):
кончик Ø1.1 мм с допуском контакта 0.12 мм, конус от 0.15 до 2.5 мм. Эта модель откалибрована для
**A1 mini**. Для P1S не подтверждена. Проверка использует её как есть.

## Ограничения

- Не заменяет физическую проверку. Сначала тестовые печати с контролем, затем обычные детали.
- Не планирует порядок печати (референс делает это при слайсинге).
- Не знает реального хотэнда, механики принтера, инерции.
- Частота выборки столкновений 0.125 мм. Очень длинные G-code файлы проверяются за минуты.
- Отсутствие ошибок — **не** сертификат безопасности.
