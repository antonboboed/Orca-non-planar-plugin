# Orca-non-planar-plugin

Экспериментальный набор инструментов для **неплоской печати верхних поверхностей** на Bambu Lab P1S (сопло 0,4 мм) в OrcaSlicer.

> **Статус: экспериментально.** Это не готовое решение и не сертифицированная проверка безопасности.
> Печатайте неплоские детали только под контролем и после собственных тестовых печатей.

## Что внутри

| Путь | Что это | Статус |
|---|---|---|
| [`docs/feasibility-orca-2.5.2.md`](docs/feasibility-orca-2.5.2.md) | Проверка: можно ли сделать неплоскую печать плагином OrcaSlicer 2.5.2 | Готово. Вывод: полный перенос как плагин невозможен, нужен патч ядра |
| [`docs/test-results.md`](docs/test-results.md) | Результаты печатей и проверок G-code на реальных файлах | Живой документ |
| [`tools/nonplanar-gcode-check/`](tools/nonplanar-gcode-check/README.md) | Независимая проверка G-code: уклон, Z, экструзия, столкновение кончика и конуса хотэнда | Черновик, 21 модульный тест |
| [`tools/nonplanar-gcode-check/plugin/`](tools/nonplanar-gcode-check/plugin/) | Плагин OrcaSlicer 2.5.2 (`psGCodePostProcess`), который проверяет экспортированный G-code и блокирует экспорт при ошибках | Черновик, не запускался в самом OrcaSlicer |

## Чего здесь НЕТ

- **Неплоской траектории.** Плагин 2.5.2 не может задать Z точек экструзионных путей (см. `docs/feasibility-orca-2.5.2.md`). Плагин только проверяет готовый G-code.
- **Полной проверки столкновений.** Блок хотэнда выше 2.5 мм над кончиком не моделируется. Такие места помечаются предупреждением.
- **Подтверждённой модели для P1S.** Модель хотэнда взята из референса, откалиброванного под A1 mini.

## Для кого и как использовать

1. Прочитайте [`docs/feasibility-orca-2.5.2.md`](docs/feasibility-orca-2.5.2.md), чтобы понимать ограничения.
2. Для неплоской печати используйте сборку с поддержкой неплоских слоёв, например [fich-l/orcaslicer-nonplanar](https://github.com/fich-l/orcaslicer-nonplanar). Порта на 2.5.2 в этом репозитории нет.
3. Для проверки экспортированного G-code установите плагин (инструкция в [`tools/nonplanar-gcode-check/README.md`](tools/nonplanar-gcode-check/README.md)) или запустите скрипт вручную:

   ```bash
   python3 tools/nonplanar-gcode-check/gcode_check.py path/to/file.gcode
   ```

4. Отсутствие ошибок в проверке не означает безопасности. Проверяйте результаты печатью, осмотром сопла и хотэнда.

## Лицензия и происхождение

Идеи и данные модели хотэнда взяты из проекта [fich-l/orcaslicer-nonplanar](https://github.com/fich-l/orcaslicer-nonplanar) (orca-nonplanar.patch, модель `NonplanarClearanceModel`). Код этого репозитория написан отдельно.
